# Getting started

A page is a Markdown file. It can have **bold** and *italic* text, `code`,
lists and tables:

| Key | What it does |
|---|---|
| Amiga+E | builds the pages |
| Amiga+R | shows them |

## A section

Headings are anchors, too: [the first page of the chapter](2-chapter/1-a-page.md#details)
goes straight to a heading of another page.
