{$PROJECT}
{$PURPOSE}

  Build/Build Project (Amiga+E)  compiles the program with {$COMPILER}
  Build/Run (Amiga+R)            starts "{$NAME}" in a console window
  Build/Debug (Amiga+D)          starts the debug build in EDBG

The debug build is the program with debug information. Choose "Debug
build" in Build/Build Command and build it before debugging; choose
"Build" again for the normal program.

The commands are in .tinydev/project.json (Project/Project Settings...).
