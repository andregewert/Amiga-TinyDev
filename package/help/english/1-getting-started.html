Getting Started

Start TinyDev from its icon or from the Shell:

TinyDev <file> ...

Files given as project icons are opened in tabs.

Project/Iconify (Amiga+I) or the iconify gadget of the window puts TinyDev on the Workbench as an icon; a double-click on it brings the window back, with the find window and the bookmark list if they were open.
