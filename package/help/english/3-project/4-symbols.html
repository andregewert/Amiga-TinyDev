Symbols

TinyDev-Scout reads the sources of the project and of the open documents and finds their symbols (functions, types, macros, variables, constants) and simple errors; the status line shows how many the current document has. Scout starts with TinyDev; Project/Settings..., Advanced, switches it off.

View/Symbol List shows the symbols of the current file in the order of their lines, or those of the whole project sorted by name. A letter shows the kind: F function, T type, M macro, V variable, C constant. Filter keeps the symbols whose names contain its text (Return takes it), Kind those of one kind. A click on a column's title sorts by it, another click the other way round; the separators between the column titles can be dragged. While Scout reads a newly opened project, the line below the list says how much is still waiting. The line below the list shows the selected symbol's kind and declaration. A double-click or Go to puts the cursor on a symbol and opens its file if needed.
