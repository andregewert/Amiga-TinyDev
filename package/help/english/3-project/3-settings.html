Project Settings

Project/Project Settings... keeps the commands of the actions Build, Run and Debug of the project. Each action may have several commands; the checked one is the one the action runs (without a check, the first one). Add, Edit, Remove, Up and Down change the list of the action shown, a double click edits a command.

A command is a Shell command line, for example make; several lines run as a script. It runs in the project drawer, or in the drawer given. In a command, {file} stands for the active document, {base} for the same without its extension and {project} for the project drawer. Put quotes around them if a name may contain spaces.

Build/Build Project (Amiga+E) saves the modified documents and runs the default Build command in the background; its output appears in the output window (View/Output Window), which also tells how it ended. Stop ends it. Build/Run (Amiga+R) and Build/Debug (Amiga+D) start their default command in a console window of their own. The toolbar has buttons for all three. Commands get a stack of 64 KB; a Stack line in the command sets another.

The page Include Drawers lists drawers with headers, for example those of the NDK or of the compiler. TinyDev-Scout reads the headers the project includes from there, so Go to Definition and Complete also know the names of system headers. A drawer inside the project is kept relative to it.

The language chosen for a file in the File Type menu is kept in the settings too.

The settings are saved in .tinydev/project.json in the project drawer, a file that may be edited by hand and kept with the project.
