Working with Projects

The drawer opened in the folder tree (Project/Open Directory...) is the project. Features that refer to the project work on the files below it. Opening another drawer closes the documents of the old project (asking about changed ones).

Project/New Shell, also in the toolbar, opens a Shell window in the project drawer (without a project, in the drawer of the current document). It stays open when TinyDev quits. Which console it uses is set in the settings.
