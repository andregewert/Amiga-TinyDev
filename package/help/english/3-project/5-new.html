New Projects and Files

Project/New Project... creates a project from a template and opens it. The templates are in the drawer Templates next to TinyDev; the tool Sprout, also next to TinyDev, does the work.

On the first page, choose a category on the left and a template in the middle; the right shows its symbol, name and description. Below, enter the project drawer (Choose... opens a file requester, where a new drawer may be named). Sprout creates the drawer if it does not exist; an existing one must be empty. The project name is optional; without one, the project is named after its drawer.

Next shows the values the template asks for, with their defaults filled in: a default may refer to the project name or another value, and it is filled in anew as long as the field has not been changed. Values marked with * must be filled in. Hold the mouse over a field for its description.

Create makes the project. If something goes wrong, Sprout's messages are shown, nothing is left behind, and the window stays open. Otherwise the new drawer becomes the project (the documents of the old project are closed first) and the template's main files are opened.

If a template brings an icon of its own, the window shows it instead of the symbol.

Project/New File from Template... works the same way with file templates, for example a C module with its header. Instead of the project name and drawer it asks for the drawer the files go into (suggested: the drawer of the current document, else the project drawer); files that exist are not overwritten. The new files are opened.

A template is a drawer or an LhA archive with a file template.json (name, description, category, the values) and a drawer files with the files of the new project. In their names and contents, {$NAME} stands for the value NAME. Sprout can also be used in the Shell; the documentation of the template format comes with the sources (src/sprout/docs/Sprout.md).
