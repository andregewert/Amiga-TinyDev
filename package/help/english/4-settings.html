Settings

Project/Settings... sets the window and what is shown at the start (General), the colours and the toolbar. The settings are saved as tool types of the TinyDev icon.

Advanced: whether TinyDev-Scout analyses the sources (it finds their symbols and errors; the status line shows how many the current document has), and the drawer for temporary files: Scout's copies of changed documents and the scripts of the Build menu. T:, in the RAM disk, is fastest; a drawer on a hard disk saves memory. The Shell window is the console of Project/New Shell: a handler such as CON: or VNC:, whose window opens below the main window, or a whole window such as CON:0/20/640/200/Shell/CLOSE.

The View menu shows and hides the folder tree, the line numbers and the minimap for the current session only; at the next start TinyDev shows what the settings say. The tool windows (bookmark list, output window) are shown and hidden there as well; View/Snapshot Tool Windows saves where they are and which are open.
