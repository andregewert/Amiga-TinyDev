Settings

Project/Settings... sets the window and what is shown at the start (General), the colours and the toolbar. The settings are saved as tool types of the TinyDev icon.

The View menu shows and hides the folder tree, the line numbers and the minimap for the current session only; at the next start TinyDev shows what the settings say. The tool windows (bookmark list, output window) are shown and hidden there as well; View/Snapshot Tool Windows saves where they are and which are open.
