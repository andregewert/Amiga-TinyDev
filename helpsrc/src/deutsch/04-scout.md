# Analyse-Funktionen

Die Quelltext-Analyse-Funktionen bieten neben einer Syntax-Hervorhebung
erweiterte Funktionen wie etwa eine Erkennung von Symboldefinitionen,
die (einfache) Erkennung von Fehlern im Quelltext, eine Autovervollständigung
im Editor und das Springen zu Definitionen oder eingebundenen Dateien.

Für die Analyse-Funktionen kommt mit Scout ein Commodity zum Einsatz.
Diese wird von TinyDev bei Bedarf automatisch gestartet. Es muss also
nicht in das Verzeichnis `WBStartup` kopiert werden (ein automatischer
Start beim Laden der Workbench wäre in den seltensten Fällen sinnvoll).
