# Git-Integration

Unter Einstellungen / Git kann eine experimentelle Unterstützung
für grundlegende Git-Funktionen eingeschaltet werden. Zu den 
unterstützten Funktionen gehören:

- Dateistatus im Verzeichnisbaum
- Commit, Fetch, Pull und Push
- Einfache Verlaufsanzeige
- Darstellung von Dateiänderungen
- Lokale Tags

Die Git-Integration erfolgt über
[am-git](https://aminet.net/package/dev/misc/am-git)
von Anders Kjeldsen.
am-git muss separat installiert werden.
Getestet wurde TinyDev mit am-git 0.12.1. Dabei handelt
es sich um ein frühes Release, das noch bestimmte
Einschränkungen hat. Insgesamt ist die Git-Integration
damit noch als experimentell zu betrachten.

Außerdem wird für ein brauchbares Arbeiten ein relativ
schneller Amiga und eine möglichst schnelle Festplatte
benötigt. Alleine das Executable von am-git ist immerhin
fast 5 MB groß!
