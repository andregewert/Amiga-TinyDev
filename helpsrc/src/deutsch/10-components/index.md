# Komponenten aus TinyDev selbst verwenden

TinyDev ist modular aufgebaut. Das bedeutet, dass es einerseits
ohne Änderung von TinyDev selbst erweitert werden kann; andererseits
können bestimmte Komponenten, die ursprünglich für TinyDev entwickelt
worden sind, auch in eigenen Anwendungen benutzt werden können.

Dieser Teil der Hilfeseiten gibt nur einen groben Überblick.
Wer sich für die einzelnen Komponenten interessiert, sollte sich
möglichst auf den Github-Seiten des TinyDev-Projektes umschauen,
weil dort die ursprüngliche und aktuellsten Dokumentation zur Verfügung
steht.

|Komponente|Einsatzzweck|
|---|---|
|[HelpViewer](01-helpviewer.md)|Anzeige von HTML-Seiten mit Inhaltsverzeichnis|
|[ReAction-Gadgets](02-reaction-gadgets.md)|Gadget-Klassen für Verzeichnisbaum, Editor-Minimap und HTML-Rendering|
|[Scout](03-scout.md)|Werkzeuge für die Analyse von Quelltexten|
