# Git Integration

Under Settings / Git, experimental support for basic git functions can be
switched on. The supported functions include:

- File status in the folder tree
- Commit, Fetch, Pull and Push
- A simple history view
- Showing the changes of a file
- Local tags

The git integration works through
[am-git](https://aminet.net/package/dev/misc/am-git)
by Anders Kjeldsen.
am-git must be installed separately.
TinyDev has been tested with am-git 0.12.1. This is an early release
that still has certain limitations. Overall, the git integration is
therefore still to be considered experimental.

Furthermore, working with it comfortably needs a fairly fast Amiga and a
hard disk as fast as possible. The am-git executable alone is almost
5 MB in size!
